# Тесты

Сквозные проверки приложения в настоящем браузере. Firebase подменяется
заглушкой `fake-firebase.js` — базой в памяти вкладки, поэтому тесты ничего
не пишут в боевую базу и не требуют сети.

## Как запустить

```bash
npx http-server -p 8199 -s .      # из корня проекта, в отдельном терминале
node tests/match.mjs              # матч: зоны, отмена, реванш, рейтинг, профиль
node tests/social.mjs             # история, личные встречи, соперники, ссылка
```

Нужен установленный `playwright` (`npm i -D playwright`). Адрес сервера можно
переопределить через `BASE`, папку для скриншотов — через `OUT`.

Оба скрипта завершаются с ненулевым кодом, если хоть одна проверка не прошла,
так что их можно ставить в CI как есть.
